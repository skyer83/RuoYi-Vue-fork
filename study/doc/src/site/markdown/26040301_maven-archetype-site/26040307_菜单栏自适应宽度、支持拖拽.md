# 菜单栏自适应宽度、支持拖拽

## 功能概述

为 Maven Site 左侧菜单栏添加自适应宽度和拖拽调整功能，支持以下特性：

1. **自适应宽度** - 菜单栏根据内容自动调整宽度
2. **拖拽调整** - 通过拖拽右侧边缘调整菜单栏宽度
3. **宽度范围限制** - 最小 180px，最大 500px
4. **状态持久化** - 使用 localStorage 保存宽度，刷新页面后保持
5. **响应式布局** - 小屏幕时自动适配

## 实现方式

### 1. CSS 样式 (site.css)

在 `src/site/resources/css/site.css` 中添加以下样式：

```css
/*
 * 自定义样式：菜单栏宽度自适应 + 拖拽调整 + 选中高亮 + 菜单折叠
 */

/* 左侧菜单栏内容 */
#navcolumn li.none {
    text-indent: 0;
    margin-left: 0;
}

/* 左侧菜单栏自适应宽度 */
#leftColumn {
    width: auto !important;
    min-width: 180px;
    max-width: 350px;
    white-space: nowrap;
    position: relative;
}

/* 菜单项内容不换行，确保宽度计算正确 */
#leftColumn li {
    white-space: nowrap;
    position: relative;
}

/* 主内容区域自动填充剩余空间 */
#bodyColumn {
    display: block;
    margin-left: 220px;
    transition: margin-left 0.1s ease;
}

/* 拖拽条样式 */
#menuResizer {
    position: absolute;
    right: 0;
    top: 0;
    bottom: 0;
    width: 5px;
    cursor: col-resize;
    background: transparent;
    z-index: 1000;
}

#menuResizer:hover {
    background: #ccc !important;
}

/* 响应式布局：小屏幕时菜单占满宽度 */
@media screen and (max-width: 768px) {
    #leftColumn {
        width: 100% !important;
        max-width: 100%;
        float: none;
    }
    
    #bodyColumn {
        margin-left: 0 !important;
        float: none;
    }
    
    #menuResizer {
        display: none;
    }
}
```

### 2. JavaScript 代码 (pom.xml)

在 `pom.xml` 的 replacer 插件配置中注入拖拽功能的 JavaScript 代码：

```xml
<replacement>
    <token><![CDATA[</body>]]></token>
    <value><![CDATA[<script>
    (function() {
      document.addEventListener('DOMContentLoaded', function() {
        // ========== 侧边栏拖拽调整宽度 ==========
        var leftColumn = document.getElementById('leftColumn');
        var bodyColumn = document.getElementById('bodyColumn');
        if (!leftColumn || !bodyColumn) return;

        // 创建拖拽调整条
        var resizer = document.createElement('div');
        resizer.id = 'menuResizer';
        resizer.style.cssText = 'position:absolute;right:0;top:0;bottom:0;width:5px;cursor:col-resize;background:transparent;z-index:1000';
        leftColumn.style.position = 'relative';
        leftColumn.appendChild(resizer);

        // 拖拽状态变量
        var isDragging = false;
        var startX = 0;
        var startWidth = 0;

        // 鼠标按下开始拖拽
        resizer.addEventListener('mousedown', function(event) {
          isDragging = true;
          startX = event.clientX;
          startWidth = leftColumn.offsetWidth;
          document.body.style.cursor = 'col-resize';
          document.body.style.userSelect = 'none';
          event.preventDefault();
        });

        // 鼠标移动时调整宽度
        document.addEventListener('mousemove', function(event) {
          if (!isDragging) return;
          var newWidth = Math.max(180, Math.min(500, startWidth + (event.clientX - startX)));
          leftColumn.style.width = newWidth + 'px';
          leftColumn.style.maxWidth = newWidth + 'px';
          bodyColumn.style.marginLeft = (newWidth + 20) + 'px';
          localStorage.setItem('menuWidth', newWidth);
        });

        // 鼠标释放结束拖拽
        document.addEventListener('mouseup', function() {
          if (isDragging) {
            isDragging = false;
            document.body.style.cursor = '';
            document.body.style.userSelect = '';
          }
        });

        // 鼠标悬停效果
        resizer.addEventListener('mouseenter', function() { this.style.background = '#ccc'; });
        resizer.addEventListener('mouseleave', function() { if (!isDragging) this.style.background = 'transparent'; });

        // 恢复保存的宽度
        var savedWidth = localStorage.getItem('menuWidth');
        if (savedWidth) {
          savedWidth = parseInt(savedWidth);
          leftColumn.style.width = savedWidth + 'px';
          leftColumn.style.maxWidth = savedWidth + 'px';
          bodyColumn.style.marginLeft = (savedWidth + 20) + 'px';
        }
      });
    })();
    </script></body>]]></value>
</replacement>
```

## 功能说明

### 1. 自适应宽度

- `#leftColumn` 设置 `width: auto !important` 实现自适应
- `min-width: 180px` 确保最小宽度
- `max-width: 350px` 限制最大宽度（拖拽时可突破此限制至 500px）
- `white-space: nowrap` 防止菜单项换行

### 2. 拖拽调整

- 在 `#leftColumn` 右侧创建 5px 宽的拖拽条 (`#menuResizer`)
- 鼠标悬停时显示灰色背景提示可拖拽
- 拖拽时限制宽度范围：180px ~ 500px
- 拖拽过程中禁用文本选择 (`userSelect: 'none'`)

### 3. 主内容区域联动

- `#bodyColumn` 使用 `margin-left` 跟随菜单栏宽度变化
- 添加 `transition: margin-left 0.1s ease` 实现平滑过渡
- 默认 `margin-left: 220px`（菜单宽度 200px + 间距 20px）

### 4. 状态持久化

- 使用 `localStorage.setItem('menuWidth', width)` 保存当前宽度
- 页面加载时读取 `localStorage.getItem('menuWidth')` 恢复宽度
- 宽度值使用 `parseInt()` 转换为整数

### 5. 响应式布局

- 屏幕宽度小于 768px 时：
  - 菜单栏占满整个屏幕宽度
  - 主内容区域下移（`margin-left: 0`）
  - 隐藏拖拽条（`display: none`）

## 关键 CSS 类说明

| 选择器 | 作用 |
|-------|------|
| `#leftColumn` | 左侧菜单栏容器 |
| `#bodyColumn` | 主内容区域 |
| `#menuResizer` | 拖拽调整条 |
| `#leftColumn li` | 菜单项（防止换行） |

## 关键 JavaScript 变量说明

| 变量名 | 说明 |
|-------|------|
| `leftColumn` | 左侧菜单栏 DOM 元素 |
| `bodyColumn` | 主内容区域 DOM 元素 |
| `resizer` | 拖拽条 DOM 元素 |
| `isDragging` | 是否正在拖拽 |
| `startX` | 拖拽开始时的鼠标 X 坐标 |
| `startWidth` | 拖拽开始时的菜单栏宽度 |
| `savedWidth` | 从 localStorage 读取的保存宽度 |

## 依赖

- `maven-site-plugin` 3.12.1
- `replacer` 插件 1.5.3（用于在构建后注入 JavaScript）

## 构建

```bash
mvn clean site -DskipTests
```

构建完成后，所有 HTML 文件都会自动注入菜单栏拖拽调整功能。

## 使用说明

1. **自适应宽度**：菜单栏会根据菜单内容自动调整宽度
2. **拖拽调整**：将鼠标移到菜单栏右边缘，光标变为左右箭头时按住拖拽
3. **宽度限制**：拖拽时宽度限制在 180px ~ 500px 之间
4. **状态保存**：调整后的宽度会自动保存，刷新页面后保持
5. **移动端适配**：屏幕宽度小于 768px 时，菜单栏自动占满宽度，拖拽功能隐藏
