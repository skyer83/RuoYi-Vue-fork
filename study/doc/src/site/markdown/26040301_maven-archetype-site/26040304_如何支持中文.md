# 如何支持中文

在 Maven 站点文档的**国际化（i18n）体系**中，支持中文的核心逻辑与之前解释的**法语（`site_fr.xml`）**完全一致——遵循**“语言代码+专属配置文件”**的规范，通过**`site_zh.xml`**（中文导航配置）与**中文文档**的配合实现。以下结合**实战步骤、示例配置、注意事项**展开深度解答：

---

## 一、核心逻辑：中文支持的本质
Maven Site Plugin 的国际化机制基于**“语言代码后缀”**与**`locales`参数激活**，中文相关的关键定义如下：
- **中文语言代码**：遵循 ISO 639 标准，用 **`zh`** 表示（若需区分简体/繁体，可扩展为 `zh-CN`（简体）、`zh-TW`（繁体））；
- **中文导航配置文件**：命名为 **`site_zh.xml`**（或 `site_zh-CN.xml`  for 简体），作用与 `site.xml`（默认语言）、`site_fr.xml`（法语）一致，仅定义**中文文档的导航结构**；
- **激活条件**：需在 `pom.xml` 的 `maven-site-plugin` 中通过 `<locales>` 参数声明支持中文（`zh`）。


## 二、实战步骤：从0到1支持中文
以**`maven-archetype-site`** 原型生成的站点为例，完整步骤如下：


### 1. 生成基础站点结构（回顾前文）
先用 `maven-archetype-site` 生成含默认 `site.xml` 的站点目录（若已完成可跳过）：
```bash
mvn archetype:generate \
  -DgroupId=com.example \
  -DartifactId=demo-site-zh \
  -DarchetypeGroupId=org.apache.maven.archetypes \
  -DarchetypeArtifactId=maven-archetype-site \
  -DarchetypeVersion=1.4
```


### 2. 创建**中文导航配置文件** `site_zh.xml`
复制默认的 `site.xml`，重命名为 **`site_zh.xml`**，并将导航文本改为**中文**（保持结构一致）：

```xml
<!-- site_zh.xml（中文版导航配置） -->
<?xml version="1.0" encoding="UTF-8"?>
<project name="我的文档站点">
  <body>
    <menu name="主导航">
      <item name="首页" href="index_zh.html"/> <!-- 中文首页 -->
      <item name="快速开始" href="quickstart_zh.html"/> <!-- 中文快速开始 -->
      <item name="API 文档" href="api_zh.html"/> <!-- 中文 API 文档 -->
      <item name="常见问题" href="faq_zh.html"/> <!-- 中文 FAQ -->
    </menu>
  </body>
</project>
```

**关键说明**：
- 文件名必须为 `site_zh.xml`（或 `site_zh-CN.xml`，需与 `locales` 参数对应）；
- 所有链接（`href`）需指向**中文文档**（如 `index_zh.html`，而非默认的 `index.html`）。


### 3. 编写**中文文档**
在 `src/site` 目录下（如 `asciidoc` 或 `apt` 子目录），创建**中文内容的文档文件**，注意：
- **字符编码**：必须用 **UTF-8**（避免乱码）；
- **文件名后缀**：与导航配置对应（如 `index_zh.md`、`quickstart_zh.apt`）。

示例（`src/site/asciidoc/index_zh.md`，用 Markdown 写的中文首页）：
```markdown
# 欢迎来到我的项目文档

## 项目简介
这是一个**支持中文**的 Maven 站点文档示例，演示如何通过 `site_zh.xml` 实现国际化。

## 核心功能
- 用 `site_zh.xml` 定义中文导航；
- 用 UTF-8 编码编写中文文档；
- 通过 `mvn site` 生成中文站点。

## 快速开始
1. 克隆仓库：`git clone https://github.com/xxx/demo-site-zh.git`；
2. 构建站点：`mvn clean site`；
3. 查看中文站点：`target/site/zh/index.html`。
```


### 4. 配置 `pom.xml` 激活中文支持
在 `maven-site-plugin` 中添加 **`locales`**（支持的语言）与 **`defaultLocale`**（默认语言，可选设为 `zh` 让中文成为默认）：

```xml
<build>
  <plugins>
    <plugin>
      <groupId>org.apache.maven.plugins</groupId>
      <artifactId>maven-site-plugin</artifactId>
      <version>3.12.1</version>
      <configuration>
        <!-- 支持的语言：英文（默认）、中文（zh） -->
        <locales>en,zh</locales>
        <!-- 可选：将中文设为默认语言（默认是 en） -->
        <defaultLocale>zh</defaultLocale>
        <!-- 站点皮肤（可选，保持美观） -->
        <skin>flatly</skin>
      </configuration>
    </plugin>
  </plugins>
</build>
```


### 5. 生成并查看中文站点
执行 Maven 命令生成站点：
```bash
mvn clean site
```

生成的**中文站点**位于：
- 若默认语言是 `zh`：`target/site/index.html`（直接用 `site_zh.xml` 导航）；
- 若默认语言是 `en`：`target/site/zh/index.html`（通过 `/zh/` 路径访问中文版）。


## 三、关键注意事项（避坑指南）
### 1. 字符编码必须统一为 UTF-8
- 所有中文文档（`.md`/`.apt`/`.xdoc`）需用 **UTF-8 编码**保存（IDE 中需设置文件编码）；
- `pom.xml` 需声明编码（避免构建时乱码）：
  ```xml
  <properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <project.reporting.outputEncoding>UTF-8</project.reporting.outputEncoding>
  </properties>
  ```


### 2. 语言代码的精确性
- 若需区分**简体中文**与**繁体中文**，可用：
    - 简体：`zh-CN`（配置文件 `site_zh-CN.xml`）；
    - 繁体：`zh-TW`（配置文件 `site_zh-TW.xml`）；
- 此时 `locales` 参数需写为 `en,zh-CN,zh-TW`。


### 3. 导航链接的准确性
- `site_zh.xml` 中的 `href` 必须指向**中文文档**（如 `index_zh.html`），而非默认的英文文档（`index.html`）；
- 若用 Asciidoctor 插件生成 HTML，中文文档的输出路径需与 `site_zh.xml` 中的链接一致（如 `target/generated-site/asciidoc/index_zh.html`）。


## 四、效果验证与扩展
### 1. 验证中文显示
生成站点后，打开 `target/site/zh/index.html`，应看到：
- 导航菜单为中文（“首页”“快速开始”等）；
- 文档内容为正常显示的中文（无乱码）；
- 代码高亮、目录生成等功能仍正常工作（延续之前的 Asciidoctor 配置）。


### 2. 扩展：多语言共存
若需同时支持**中、英、法**三国语言，只需：
- 创建 `site_en.xml`（英文，默认）、`site_zh.xml`（中文）、`site_fr.xml`（法语）；
- 在 `pom.xml` 中设置 `<locales>en,zh,fr</locales>`；
- 为每个语言编写对应的文档（如 `index_en.html`/`index_zh.html`/`index_fr.html`）。


## 总结
支持中文的核心是**“用 `site_zh.xml` 定义中文导航 + 写 UTF-8 中文文档 + 激活 `zh` 语言”**，本质是将之前的“法语支持”替换为“中文支持”。关键结论是：
- **配置文件**：`site_zh.xml`（简体中文）或 `site_zh-CN.xml`（更精确）；
- **语言代码**：`zh`（或 `zh-CN`/`zh-TW`）；
- **核心步骤**：创建中文导航→写中文文档→配置 `locales`→生成站点。
