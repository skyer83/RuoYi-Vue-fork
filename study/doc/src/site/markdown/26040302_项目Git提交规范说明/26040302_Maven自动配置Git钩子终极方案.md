# 完美！给你 **Maven 自动配置 Git 钩子** 终极方案
**全程零 npm、零插件、零依赖**，团队新人拉代码后，**只要执行 Maven 构建，自动强制启用提交规范校验**，完全不用手动操作。

# 一、先在项目里建这两个文件
## 1. 新建目录：`git-hooks/commit-msg`
**文件路径：`项目根目录/git-hooks/commit-msg`**
（无后缀，就是一个脚本文件）

内容复制：
```sh
#!/bin/sh
# Git 提交规范校验（纯Git钩子，无任何依赖）

COMMIT_MSG_FILE="$1"
COMMIT_MSG=$(cat "$COMMIT_MSG_FILE")

# 必须满足：前缀 + 英文冒号 + 空格 + 描述
PATTERN="^(feat|fix|docs|style|refactor|test|chore|perf|ci|revert):\s.+"

if ! echo "$COMMIT_MSG" | grep -qE "$PATTERN"; then
  echo ""
  echo "❌ 提交失败！格式不符合规范"
  echo ""
  echo "✅ 正确格式：类型: 简要描述（冒号后必须有空格）"
  echo "示例：feat: 新增用户登录功能"
  echo ""
  echo "✅ 允许的前缀类型："
  echo "feat:     新功能"
  echo "fix:      修复bug"
  echo "docs:     文档修改"
  echo "style:    代码格式（空格、缩进、分号）"
  echo "refactor: 代码重构"
  echo "test:     测试用例"
  echo "chore:    构建/依赖/工具修改"
  echo "perf:     性能优化"
  echo "ci:       CI配置"
  echo "revert:   回滚提交"
  echo ""
  exit 1
fi
```

# 二、把这段代码直接复制到你的 pom.xml
加到 `<build>` → `<plugins>` 里面：

```xml
<!-- 自动配置 Git 提交规范钩子（纯原生，无任何依赖） -->
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-resources-plugin</artifactId>
    <version>3.3.1</version>
    <executions>
        <execution>
            <id>copy-git-hooks</id>
            <phase>initialize</phase>
            <goals>
                <goal>copy-resources</goal>
            </goals>
            <configuration>
                <encoding>UTF-8</encoding>
                <outputDirectory>${project.basedir}/.git/hooks/</outputDirectory>
                <resources>
                    <resource>
                        <directory>git-hooks/</directory>
                        <includes>
                            <include>commit-msg</include>
                        </includes>
                    </resource>
                </resources>
            </configuration>
        </execution>
    </executions>
</plugin>

<!-- 给钩子添加执行权限（仅 Unix/Mac 系统，Windows 自动跳过） -->
<plugin>
    <groupId>org.codehaus.mojo</groupId>
    <artifactId>exec-maven-plugin</artifactId>
    <version>3.1.0</version>
    <executions>
        <execution>
            <id>git-hooks-chmod</id>
            <phase>initialize</phase>
            <goals>
                <goal>exec</goal>
            </goals>
            <configuration>
                <!-- Windows 系统没有 chmod 命令，跳过此步骤 -->
                <executable>chmod</executable>
                <arguments>
                    <argument>+x</argument>
                    <argument>${project.basedir}/.git/hooks/commit-msg</argument>
                </arguments>
                <!-- 如果命令执行失败则跳过（兼容 Windows） -->
                <successCodes>
                    <successCode>0</successCode>
                </successCodes>
                <!-- Windows 下直接跳过 -->
                <skip>${skip.git.hooks.chmod}</skip>
            </configuration>
        </execution>
    </executions>
</plugin>
```

---
直接加到根节点 `project`
```xml
<!-- 根据操作系统自动配置是否跳过 chmod -->
<profiles>
    <profile>
        <id>windows</id>
        <activation>
            <os>
                <family>windows</family>
            </os>
        </activation>
        <properties>
            <skip.git.hooks.chmod>true</skip.git.hooks.chmod>
        </properties>
    </profile>
    <profile>
        <id>unix</id>
        <activation>
            <os>
                <family>unix</family>
            </os>
        </activation>
        <properties>
            <skip.git.hooks.chmod>false</skip.git.hooks.chmod>
        </properties>
    </profile>
    <profile>
        <id>mac</id>
        <activation>
            <os>
                <family>mac</family>
            </os>
        </activation>
        <properties>
            <skip.git.hooks.chmod>false</skip.git.hooks.chmod>
        </properties>
    </profile>
</profiles>
```
